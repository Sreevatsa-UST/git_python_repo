Application Under Test

GitHub (https://github.com)

Framework Goal

Instead of writing:

page.locator(xpath).click()


your test should write:

GitActions.click(SIGN_IN_BUTTON)


and all Playwright implementation should remain hidden inside your framework library.

Object Repository

Store ONLY locators.

home_page_objects.py
class HomePageObjects:

    SIGN_IN_LINK = "//a[contains(text(),'Sign in')]"

    SEARCH_BOX = "//input[contains(@placeholder,'Search')]"

    PRICING_LINK = "//a[contains(text(),'Pricing')]"


No XPath should appear anywhere else.

Pages Layer

Contains business actions.

home_page.py
class HomePage:

    def click_sign_in(self):

        ElementActions.click(
            HomePageObjects.SIGN_IN_LINK
        )

    def search_repository(self, value):

        ElementActions.enter_text(
            HomePageObjects.SEARCH_BOX,
            value
        )

Feature File Structure
login.feature
@Smoke
Feature: GitHub Login

Scenario: Navigate To Login Page

Given User launches GitHub website

When User clicks Sign In link

Then Login page should be displayed

search.feature
@Regression

Feature: Repository Search

Scenario: Search Repository

Given User launches GitHub website

When User searches repository "playwright"

Then Repository results should be displayed

Step Definitions

Keep them lightweight.

login_steps.py
@given('User launches GitHub website')

@when('User clicks Sign In link')

@then('Login page should be displayed')


No Playwright code here.

Only call page methods.
